# Generative AI

A collection of Generative AI experiments and implementations, organized by model type.

## 📂 Repository Structure

```
Generative_AI/
├── CHAT_MODEL/         # Chat/conversational LLM experiments
└── EMBEDDING_MODEL/    # Text embedding model experiments
```

- **CHAT_MODEL/** — Code and notebooks exploring conversational/chat-based generative AI models (prompting, response generation, chat pipelines).
- **EMBEDDING_MODEL/** — Code and notebooks exploring embedding models used for tasks like semantic search, similarity, and retrieval.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Omrawat11/Generative_AI.git
cd Generative_AI
```

Explore the `CHAT_MODEL` and `EMBEDDING_MODEL` folders for individual scripts/notebooks. Each may require its own dependencies — check for a `requirements.txt` inside the relevant folder, or install common packages as needed:

```bash
pip install -r requirements.txt
```
